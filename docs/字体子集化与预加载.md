## 一、站点一次首页加载的字体流量：19.2 MB → 3.9 MB

2026-09-14 用与手机 WebView 相同的 UA/视口实测 `https://www.yibianhui.cn/`：

| 阶段 | 字体流量 | 说明 |
|---|---|---|
| 改动前 | **19.19 MB** | TH-Tshyn P0+P1 13.7 MB、Klee One 2.86 MB、Sarasa 子集等 |
| 去掉字体 `<link rel=preload>` 后 | 4.94 MB | **TH-Tshyn 整体不再下载** |
| Klee One 子集化后 | **3.90 MB** | Klee One 2.86 → 1.83 MB |

### 1) 为什么去掉 preload 能省下 13.7 MB

原来的两条 `<link rel="preload" as="font">` 是**预加载扫描器**发起的：浏览器一看到就下载，
页面 JS 无法取消。而在预加载窗口里 Sarasa 尚未就位，正文先按字体栈回退 ——
Android 上没有 PingFang / 雅黑，于是回退到 `TH-Tshyn`，把 13.7 MB 的分片拉了下来。
去掉预加载后字体在 CSSOM 就绪后按需加载，`TH-Tshyn` 根本不会被选中。

代码位置：`inc/ybh/bootstrap.php::ybh_resource_hints()`（`$preloads` 现在是空数组，
要恢复就把文件名填回去，**必须与 `css/ybh.css` 的 `@font-face` 路径一字不差**）。

### 2) Klee One 子集化

Klee One 只用在首页头图那一行「一言」（`.header-info p{font-family:Klee One!important}`，
由站点自定义 CSS 指定），而一言是**随机中日文引言**。

子集语料 = 站点正文 + **GB2312 一/二级汉字（6763）** + **JIS X 0208 第 1 水准（2965）**
+ 假名 + 拉丁 + 常用标点符号。

实测覆盖率（**250+ 条未参与子集化的新一言**）：完全覆盖 **100.0%**，字符缺字率 **0/4859**。

生成命令（fontTools 4.x）：

```bash
pyftsubset KleeOne-Regular.woff2 \
  --text-file=klee_corpus_final.txt \
  --flavor=woff2 --layout-features=* --no-hinting --desubroutinize \
  --output-file=KleeOne-Regular.woff2     # 就地替换，CSS 无需改动
```

语料生成（Python 标准库即可，不需要外部词表）：

```python
import os
chars = set(open('corpus.txt', encoding='utf-8').read())        # 站点正文
def rows(codec, qu_from, qu_to):
    out = set()
    for qu in range(qu_from, qu_to + 1):
        for wei in range(1, 95):
            try: ch = bytes([qu + 0xA0, wei + 0xA0]).decode(codec)
            except Exception: continue
            if len(ch) == 1: out.add(ch)
    return out
chars |= rows('gb2312', 16, 87)     # GB2312 一级+二级汉字
chars |= rows('euc_jp', 16, 47)     # JIS X 0208 第 1 水准
for lo, hi in ((0x20,0x7E),(0x2000,0x206F),(0x2460,0x24FF),(0x25A0,0x25FF),
               (0x2600,0x26FF),(0x2700,0x27BF),(0x3000,0x303F),(0x3040,0x30FF),
               (0xFF00,0xFFEF),(0x1F300,0x1F5FF),(0x1F600,0x1F64F)):
    chars.update(chr(c) for c in range(lo, hi + 1))
open('klee_corpus_final.txt','w',encoding='utf-8').write(''.join(sorted(chars)))
```

## 二、还能再省吗

- **Klee One 再往下压**：只能砍汉字，会牺牲一言的完整度（实测按「站点语料」子集化到
  0.93 MB 时，18% 的一言会缺 1~2 个字）。当前 1.83 MB 已把缺字率压到 0。
- **TH-Tshyn（29 MB）**：现在不会被下载，但规则仍在 CSS 里（`css/ybh.css`
  的 `@font-face` 与字体栈第 4 位）。若日后又出现「整页回退到它」的情况，
  直接把 `'TH-Tshyn'` 从字体栈里去掉即可 —— 它在任何有 CJK 系统字体的平台上都不该被选中。
- **Sarasa 子集（1.24 MB）**：正文主力，已经是按站点语料子集化的结果，没有多少余量。
